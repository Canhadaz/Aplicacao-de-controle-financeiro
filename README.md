interface da aplicação foi desenvolvida com foco completo em Mobile. Portanto, não possui responsividade com relação à uma interface WEB.

inicie a partir da pasta que armazena o projeto, os seguintes comandos:

```bash
npm i
npm run start
```

depois de executado o comando `npm run start`, selecione o meio de exibição do
sistema. No caso foi utilizado o `AndroidStudio`, sendo possível selecionar
seu emulador a partir do digito da letra 'a' dentro do terminal. Com a aplicação
rodando.
